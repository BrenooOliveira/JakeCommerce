📖 Informações Adicionais

Todos os protótipos foram criados com base no documento de UseCase v1.0.0 e cobrem os principais fluxos do processo de venda da plataforma JakeCommerce:

  • Completamente independentes: cada arquivo HTML funciona isoladamente
  • Sem autenticação: assumem usuário já autenticado
  • Sem backend: apenas demonstração de UI/UX
  • Responsivos: otimizados para desktop (adaptáveis para mobile)
  • Interativos: includes modals e ações de usuário
  • Acessíveis: semântica HTML apropriada

Para mais detalhes: consulte o arquivo README.md neste diretório.
